# My_java_lab
# Матрицы комплексных чисел

Практическая работа №1. Консольное Java-приложение для работы с матрицами, элементы которых являются комплексными числами.

## Функционал

Программа позволяет создать матрицу и выполнить над ней операции:
- **Сложение** двух матриц (размеры должны совпадать)
- **Умножение** двух матриц (число столбцов первой равно числу строк второй)
- **Деление** матриц: A / B = A × B⁻¹ (B должна быть квадратной и невырожденной)
- **Транспонирование**
- **Вычисление определителя** (только для квадратных матриц)
При недопустимых операциях (разные размеры, деление на вырожденную матрицу и т.д.) программа выводит сообщение об ошибке и продолжает работу. Некорректный ввод чисел тоже обрабатывается.

## Структура проекта

- `Complex` — комплексное число и арифметика над ним (сложение, вычитание, умножение, деление)
- `ComplexMatrix` — матрица комплексных чисел и все операции над ней
- `Operation` — интерфейс с перечнем операций над матрицами
- `My_lab` — консольное меню (точка входа)

## Как запустить

1. Скомпилировать: `javac src/My_lab.java`
2. Запустить: `java -cp src My_lab`

## Пример работы
1. Введите размеры матрицы A (строки и столбцы).
2. Введите элементы: для каждого две числа через пробел, действительная и мнимая части. Дробная часть записывается через точку, например `2.5 -1`.
3. Выберите операцию в меню:

   `1` — сложить, `2` — умножить, `3` — разделить, `4` — транспонировать, `5` — определитель, `6` — ввести новую матрицу A, `0` — выход.
4. Для операций с двумя матрицами программа запросит матрицу B.

Результат выводится в виде `(действительная+мнимаяi)`.
